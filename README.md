# E-Commerce Price Tracker & Web Scraper (PHP)

Narzędzie skryptowe napisane w języku PHP służące do automatycznego pobierania, parsowania i analizy ofert oraz parametrów technicznych laptopów z serwisów e-commerce.

## Główne funkcjonalności
- Automatyczne pobieranie zawartości stron produktowych.
- Parsowanie struktur HTML/DOM i wyciąganie kluczowych parametrów (model, specyfikacja, cena).
- Zestawianie i porównywanie zebranych danych cenowych.

## Technologie
- PHP 8, cURL / DOMDocument, HTML/CSS
